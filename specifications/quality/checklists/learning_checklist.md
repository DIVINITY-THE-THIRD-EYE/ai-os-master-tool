# Learning Checklist (Gate 7)

**Responsible Agent:** A12 (Learning & Knowledge Publication Agent)
**Gate:** Gate 7 (Learning Gate)

## Data Collection
- [ ] Complete task record retrieved — **Blocking**
- [ ] Verification reports collected — **Blocking**
- [ ] Human feedback collected (if applicable) — **Advisory**
- [ ] Execution metrics retrieved from A11 — **Blocking**

## Knowledge Extraction
- [ ] Patterns extracted from execution — **Blocking**
- [ ] Lessons learned documented with evidence — **Blocking**
- [ ] Lessons classified: best_practice / anti_pattern / optimization / prompt_improvement — **Blocking**
- [ ] All lessons include: context + observation + recommendation + evidence link — **Blocking**

## Candidate Quality
- [ ] Candidate knowledge is evidence-backed with traceable source — **Blocking**
- [ ] Candidate does not conflict with existing approved policy — **Blocking**
- [ ] Candidate reviewed by validation pipeline (A07 + A08) — **Blocking**
- [ ] Candidate quality score >= 0.80 — **Blocking**

## Approval & Publication
- [ ] Candidate approved by Domain Authority (A05-*) — **Blocking**
- [ ] Human approval obtained if knowledge affects production behavior — **Blocking**
- [ ] Approval logged with approver identity and timestamp — **Blocking**
- [ ] Knowledge published to knowledge graph — **Blocking**
- [ ] Version history updated — **Blocking**
- [ ] Prompt library updated if prompt improvements approved — **Blocking**
- [ ] knowledge.published event emitted — **Blocking**
