> **Subsystem:** Phase 05 — Knowledge Platform

## 1. System Overview & ADR Repository Governance

The Decision Library acts as the authoritative enterprise registry for all Architecture Decision Records (ADRs) generated by human architects and autonomous Domain Authority agents across AI OS v4.

## 4. Supercession & Lifecycle State Machine

```text
[PROPOSED] ──► Evaluation Gate ──► [ACCEPTED] ──► Superceded Event ──► [SUPERCEDED]
    │                                  │
    ▼                                  ▼
[REJECTED]                        [DEPRECATED]
```

When an ADR transitions to `SUPERCEDED`:
1. `superceded_by` link must reference the new accepted ADR ID.
2. The Traceability Graph updates affected component links automatically.
3. Agents referencing the old ADR in active execution contexts are notified via an `ADRUpdatedEvent`.

## 5. Query & Integration Contracts

### Search ADR API Endpoint
`GET /api/v4/decisions?status=ACCEPTED&domain=KnowledgePlatform`

### Knowledge Graph Linking
Every accepted ADR is projected into the Enterprise Knowledge Graph as a `:Decision` node connected to affected `:Component` and `:Requirement` nodes via `:SATISFIES` edges.
